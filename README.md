# نظام مباشرة الطلبة المقبولين — كلية علوم الحاسوب والرياضيات

موقع يفتح على الموبايل، يقرأ باركود الطالب، يعرض اسمه مع علامة ✔، وعند الضغط على «تأكيد المباشرة» يُكتب في جوجل شيت: `تمت المباشرة` + وقت المباشرة.

## الملفات

|الملف|الوظيفة|
|-|-|
|`index.html`|واجهة الموقع (تُرفع إلى GitHub ثم Vercel)|
|`config.js`|فيه رابط الـ Apps Script فقط|
|`apps-script/Code.gs`|الكود الذي يُلصق داخل Apps Script في الشيت|

## خطوات التشغيل

### ١) Apps Script

1. افتح الشيت ← **الإضافات ← Apps Script**.
2. احذف الكود الموجود والصق محتوى `apps-script/Code.gs` ثم احفظ.
3. اختر الدالة `setup` واضغط **تشغيل ▶** ووافق على الصلاحيات.

   * تُنشأ ورقة **«الأقسام»** فيها كل قسم ورمزه السري (٤ أرقام). يمكنك تغيير الرموز يدوياً.
   * يُضاف عمود **«وقت المباشرة»** إلى ورقة1.
4. **نشر ← نشر جديد ← تطبيق ويب**:

   * التنفيذ باسم: **أنا**
   * من يملك حق الوصول: **أي شخص**
5. انسخ الرابط الذي ينتهي بـ `/exec`.

### ٢) ضبط الرابط

افتح `config.js` وضع الرابط مكان `PUT\_APPS\_SCRIPT\_EXEC\_URL\_HERE`.

### ٣) GitHub ثم Vercel

1. ارفع الملفات إلى مستودع على GitHub.
2. في vercel.com ← **Add New ← Project** ← اختر المستودع ← **Deploy** (بدون أي إعدادات، Framework: Other).
3. أعطِ كل مقرر قسم الرابط + رمز قسمه من ورقة «الأقسام».

> أي تعديل على GitHub يُنشر تلقائياً في Vercel.
> إذا عدّلت Code.gs لاحقاً: \*\*نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد\*\* (حتى يبقى الرابط نفسه).

## محتوى الباركود

يكفي أن يحمل الباركود **رقم التسلسل** للطالب (مثل `15`). وإذا كان يحتوي نصاً أطول فيه الرقم (مثل `15|محمد|الامن السيبراني`) فالموقع يستخرج الرقم تلقائياً.

## الحالات التي يعرضها الموقع

* ✔ أخضر: الطالب مقبول في هذا القسم ← زر «تأكيد المباشرة».
* ⚠ برتقالي: الطالب باشر مسبقاً (مع الوقت).
* ✖ أحمر: الطالب مقبول في قسم آخر (يظهر اسم القسم) أو غير موجود.
